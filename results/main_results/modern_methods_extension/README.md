# Modern-method extension under the original all-dataset protocol

This folder contains the later TWStream and FRA-ART executions on CoverType, Electricity, TweetEval, and Synthetic GMM. They use the same study environment, prepared stream order, preprocessing, observation coverage, macro evaluator, and ARI/NMI definitions as the original all-dataset experiment. They extend rather than replace the original results.

- `summary.csv`: manuscript-facing values.
- `complete_window_summary_raw.csv`: full-precision numerical table retained with the study results.

Every row in `summary.csv` records 100% observation coverage.

# All-dataset adaptive-rank statistics

This folder contains the adaptive-rank statistics used by the final manuscript.

- `rank_summary.csv`: manuscript table values.
- `rank_seedwise.csv`: 4 datasets × 10 seeds = 40 seed-level records.
- `rank_distribution.csv`: empirical rank distribution.
- `raw_logs/`: retained run logs associated with the seed-level records.

The permitted upper rank is 32 and the observed ranges are recorded in `rank_summary.csv`.
